# 🏖️ 2D Sand Physics Simulator

A visually captivating 2D sandbox game built in Rust, featuring realistic physics-based sand simulation. Players can interact with granular materials that behave naturally, creating dynamic and engaging environments.

## Key Features

- Real-time 2D physics simulation of sand and particles  
- High-performance implementation leveraging Rust's speed and safety  
- Interactive sandbox environment encouraging creativity  
- Lightweight and optimized for smooth gameplay
